# Three.js Starter

WebGL experiments built with Three.js, GSAP and Vite: shapes, shaders, scroll-driven scenes, post-processing and interaction, plus a written playbook in `PLAYBOOK.md`.

```bash
npm install
npm run dev
```

The two largest assets are left out of this repository because of their size: `public/models/model.glb` and `public/hdri/night.hdr`. Pages that load them need your own files at those paths.
