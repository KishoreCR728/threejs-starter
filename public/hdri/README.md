# HDRI Environment Maps

Drop a `.hdr` file here named `environment.hdr`.

Get free HDRIs from https://polyhaven.com/hdris (everything is CC0).

Recommendations:
- "Studio Small 09" — clean studio look
- "Kloofendal 48d Partly Cloudy" — outdoor blue sky
- "Venice Sunset" — warm dramatic
- "Brown Photostudio 02" — neutral professional

Download the **1K** resolution. 2K/4K is overkill for the web.

The current `main.js` looks for `/hdri/environment.hdr`.
