# Models

Drop `.glb` files here. They will be served at `/models/<filename>.glb`.

The current `main.js` looks for `/models/model.glb` by default — either rename your file to `model.glb` or update the path in `src/main.js`.

Free model sources:
- https://poly.pizza/ (low-poly, fast loading)
- https://sketchfab.com/3d-models?features=downloadable&sort_by=-likeCount (filter for "Downloadable" + "glTF")
- https://quaternius.com/ (free packs)

For your first try: pick something simple (chair, plant, low-poly object), under 5 MB, in `.glb` format.
